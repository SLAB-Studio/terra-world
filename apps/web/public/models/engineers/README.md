# Engineer character

`quaternius-worker.glb` is the complete animated **Worker** character by
Quaternius, downloaded from Poly Pizza on 2026-09-12.

- Source: https://poly.pizza/m/Yg2bQZO6Hj
- Original pack: https://quaternius.com/packs/ultimatemodularcharacters.html
- License: CC0 1.0 Universal (public domain)
- SHA-256: `9c28614f465b7dc105f908c20c22fc045f4b07caf8c5ef0e9f8049eceb6dd38d`

The GLB contains the fitted hard hat, high-visibility vest, work trousers,
boots, one humanoid armature, and embedded idle, walk, run, and wave clips. The
player and Leo use separate material instances for their blue and red uniforms;
no geometric costume pieces are attached at runtime.

Terra uses the asset's idle, walk, and wave clips. The source run clip is kept in
the original GLB for provenance but is not played because its loop has a visible
foot seam; fast travel remains distance-driven with the seamless walk cycle.
